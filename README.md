# imdb-sentiment-analysis
This project performs sentiment analysis on real IMDb movie reviews using Natural Language Processing and machine learning. It includes text preprocessing, stopword removal, TF-IDF vectorization, and Logistic Regression to classify reviews as positive or negative, with evaluation metrics and custom predictions.
# Sentiment Analysis using NLP

This project performs sentiment analysis on text reviews using Natural Language Processing techniques.

## Features
- Text preprocessing
- TF-IDF vectorization
- Logistic Regression classifier

## How to Run
1. Install dependencies  
   pip install -r requirements.txt  

2. Run the script  
   python sentiment_analysis.py
